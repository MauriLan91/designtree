# dt-schema core schemas

Copied unchanged from the `schemas/` directory of
[dt-schema](https://github.com/devicetree-org/dt-schema) 2026.9
(BSD-2-Clause, see `LICENSE.txt`).

Kernel bindings refer to these files as `/schemas/types.yaml`,
`/schemas/clock/clock.yaml` and so on, but the kernel tree does not contain
them. The indexer embeds them to resolve property types. To update, replace
`schemas/` with the directory of a newer dt-schema release.
